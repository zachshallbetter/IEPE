# Qualify an IEPE Outcome

Bind every assertion to the issue, candidate, environment, evaluator, provenance, and reproduction method. Distinguish artifact existence from evaluation and evaluation from empirical validation.

Use the weakest justified maturity when evidence differs across dimensions:

```text
Documented != Implemented != Tested != Empirically Validated
```

Missing provenance, required dimensions, evaluator independence, reproduction, or protected-action authority blocks promotion. Retain failed, negative, bounded, and inconclusive outcomes.

Return an evidence bundle, qualification, limitations, evidence gaps, promotion recommendation, and named authority required for any next promotion.
