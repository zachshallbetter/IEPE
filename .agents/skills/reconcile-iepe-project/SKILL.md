# Reconcile an IEPE Project

Begin read-only. Verify the pinned protocol, local profile, authority chain, repository or workspace identity, work graph, dependency state, claims, implementation, reviews, deployments, and evidence.

Classify findings as established, inferred, proposed, observed, or unresolved. Observation does not grant authority. Record contradictions, stale claims, incomplete issue contracts, unsupported maturity, and protected actions.

Return a typed reconciliation result with verified identities, discrepancies and provenance, blockers and required authority, material unknowns, the first candidate Ready issue, and mutations that remain unauthorized.

Do not repair state during the reconciliation pass unless mutation authority was explicitly included in the issue contract.
