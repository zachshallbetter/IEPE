# IEPE-CORE-004: Build the First Cross-Domain Adoption Example

## Intent

Prove that the adoption kit can describe a meaningful non-software project without modifying core doctrine.

## Type

Experiment

## Parent

M1: Adoption Kit

## Hypothesis

An editorial or creative-production project can adopt IEPE using only a project profile, intent and experience contracts, work items, evidence, and domain-specific evaluators.

## Objective

Create and execute one self-contained example from intent through evidence and promotion decision, then record every core ambiguity or missing extension point.

## Acceptance criteria

- The example is outside software engineering.
- All example records validate against the current schemas.
- The example uses the coordinator state sequence.
- At least one candidate is evaluated against visible dimensions.
- A negative or rejected direction is preserved.
- Qualification and promotion remain separate.
- No example-specific concept is added to core unless proven generally necessary.
- Adoption gaps are recorded as evidence for protocol refinement.

## Evidence required

- Valid project profile.
- Valid experience contract.
- Valid issue, evaluation, evidence, and promotion records.
- Coordinator execution trace.
- Gap and negative-result record.
- Conformance output.

## Constraints

- The example must not pretend to be a real external field validation.
- Human-value claims remain documented or tested unless actual observation exists.
- The example stays reversible and has no external side effects.

## Permissions

- Local example artifacts: allowed.
- External publication, communication, spending, and deployment: not authorized.

## Stop conditions

- The example requires weakening a core evidence or authority invariant.
- The domain cannot supply an honest evaluator for its central claim.

## Status

Verified

## Claim maturity

Tested

## Result

The exhibition-guide pilot completed the full internal path from intent through promotion decision. Six example records validate against the core schemas. Candidate B was promoted only to the internal example baseline. Candidate A was retained as a context-specific negative result. Human comprehension and lived accessibility remain unobserved.
