# Exhibition Guide Pilot

This synthetic pilot tests IEPE against a non-software editorial and experience-design project.

The fictional project creates a one-page orientation guide for first-time visitors entering a small exhibition titled **Ways of Seeing Water**. The guide should help visitors choose where to begin without prescribing a correct route or explaining the artworks for them.

No real visitors participated. The pilot can test structural intent alignment, editorial constraints, candidate comparison, evidence lineage, and promotion separation. It cannot validate comprehension, emotional quality, accessibility in lived use, or visitor behavior.

## Pilot path

```text
Project profile
  -> Intent and experience contract
  -> Authorized issue
  -> Two editorial candidates
  -> Rule-based evaluation
  -> Rejected-direction record
  -> Evidence bundle
  -> Internal example-baseline promotion
```

## Qualification

The example is **tested** as a protocol and schema exercise. Its visitor experience remains **specified**, not observed or empirically validated.
